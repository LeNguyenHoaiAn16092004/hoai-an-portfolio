# Quality Rules

Definition of done:

## Code

- TypeScript has no relevant errors
- Lint passes
- Build passes
- No obvious dead code

## Browser

- No console errors
- Navigation works
- External links work
- Error states behave sensibly

## Responsive

Check relevant desktop, tablet, and mobile sizes.

For layout-heavy work also check landscape.

## Theme

Check light and dark.

## Accessibility

Check keyboard navigation, focus, semantic structure, contrast, and reduced
motion.

## Performance

Avoid unnecessary large assets, expensive continuous effects, layout
thrashing, and blocking 3D.

If a visual effect causes performance problems, reduce the effect before
sacrificing content usability.
