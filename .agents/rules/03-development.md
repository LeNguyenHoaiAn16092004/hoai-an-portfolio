# Development Rules

Use TypeScript.

Prefer functional React components.

Keep components focused and reusable.

Separate:

- content/data
- presentation
- animation
- 3D
- utilities
- theme logic

Do not create giant components.

Do not use `any` unless there is a documented reason.

Do not disable lint rules simply to pass lint.

Do not suppress TypeScript errors.

Do not install dependencies without a technical justification.

Prefer platform APIs and CSS when they are sufficient.

Keep 3D code isolated and lazily loaded when practical.

Avoid user-agent sniffing.

Do not put secrets in frontend code.
