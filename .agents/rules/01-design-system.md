# Design Rules

The site must not look like a generic modern developer portfolio.

Prefer:

- editorial composition
- asymmetric layout
- oversized typography
- controlled whitespace
- technical metadata
- subtle retro influence
- experimental but intentional composition

Avoid:

- glassmorphism
- purple/blue SaaS gradients
- generic hero templates
- repetitive card grids
- skill progress bars
- excessive rounded containers
- excessive shadows
- icon clutter

Use Light and Dark as intentionally art-directed themes.

3D and motion are part of the visual language, but content always has priority.

Never copy JayGood or another reference site directly.
Use references only for high-level inspiration.
