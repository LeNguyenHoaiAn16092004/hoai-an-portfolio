# UI/UX Rules

The site is an interactive digital experience.

Responsive behavior must be designed for:

- desktop
- tablet
- mobile
- foldable-like narrow/wide states
- portrait
- landscape

Never rely on hover for essential functionality.

Every hover interaction must have an equivalent touch/keyboard path.

Prefer CSS-first responsive behavior.

Do not create horizontal overflow.

Maintain readable line lengths and touch-friendly targets.

Every major interactive element must have a visible focus state.

Respect prefers-reduced-motion.
