# Build Feature Workflow

Use this workflow for substantial feature work.

1. Read all relevant documentation.
2. Identify the roadmap item.
3. Inspect the existing implementation.
4. State a short implementation plan.
5. Implement the smallest coherent solution.
6. Reuse existing components/tokens.
7. Run lint.
8. Run build.
9. Start the dev server if the change is visual.
10. Inspect the result in the browser.
11. Test relevant responsive states.
12. Test light/dark if affected.
13. Test reduced motion if motion is affected.
14. Fix discovered problems.
15. Re-run validation.
16. Update ROADMAP.md.
17. Summarize changes and verification.
