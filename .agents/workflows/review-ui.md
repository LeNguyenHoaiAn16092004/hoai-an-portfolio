# UI Review Workflow

1. Read DESIGN.md, DEVICE_SPECIFICATION.md, and MOTION.md.
2. Open the relevant route in the browser.
3. Inspect desktop.
4. Inspect tablet.
5. Inspect mobile.
6. Inspect light theme.
7. Inspect dark theme.
8. Inspect keyboard navigation.
9. Inspect reduced motion when relevant.
10. Look for:
   - overflow
   - broken hierarchy
   - unreadable text
   - weak contrast
   - excessive motion
   - inconsistent spacing
   - accidental generic/template appearance
   - hover-only functionality
11. Fix the highest-impact issues.
12. Re-test.
13. Report what was changed.
