# Project

## Name

Hoài An — Personal Portfolio

## Product type

Interactive personal developer portfolio.

## Primary purpose

Present the developer's work, technical thinking, experiments, skills,
background, and contact information in a memorable but professional digital
experience.

## Target audience

- Recruiters
- Engineering managers
- Technical interviewers
- Developers
- Potential collaborators

## Positioning

This is not a conventional online CV.

It should feel like a personal digital workshop / developer archive where
projects and technical thinking are the main evidence of ability.

## Design keywords

- Retro
- Editorial
- Experimental
- Technical
- Asymmetric
- Handcrafted
- Controlled chaos
- Interactive

## Experience keywords

- Immersive
- Responsive
- Physical
- Subtle
- Curious
- Fast
- Intentional

## Main differentiator

The website should look deliberately designed rather than generated from a
standard portfolio template.

It should combine unusual editorial composition with developer-oriented
information architecture, selective 3D, and a coherent motion language.

## Non-goals

Do not turn the portfolio into:

- A SaaS dashboard
- A generic developer portfolio
- A glassmorphism showcase
- A WebGL demo with little useful content
- A CV dump
- A content management system unless a real requirement appears

## Core principles

1. Content is more important than effects.
2. Design can be unconventional without becoming confusing.
3. Animation should support hierarchy and storytelling.
4. 3D should be progressive enhancement.
5. Every important interaction must work without hover.
6. Mobile is a first-class experience.
7. Accessibility and performance are product requirements.
8. Prefer simple architecture over unnecessary dependencies.
